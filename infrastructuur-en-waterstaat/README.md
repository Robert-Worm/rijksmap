# Ministerie van Infrastructuur en Waterstaat

De pagina's van dit ministerie op de Rijksmap: [www.rijksmap.nl/infrastructuur-en-waterstaat/](https://www.rijksmap.nl/infrastructuur-en-waterstaat/).

- `index.html` is de pagina van het ministerie zelf: leiding, organisatie en rapporten.
- Elke submap is een organisatieonderdeel (directoraat-generaal, dienst, ZBO of RWT) met een eigen pagina.

Deze pagina's worden gegenereerd uit de kaartdata; wijzigingen gaan via de bron, niet met de hand. Zie [CONTRIBUTING.md](../CONTRIBUTING.md).
