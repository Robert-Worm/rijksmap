# Leesprotocollen

Dit zijn de letterlijke instructies waarmee de AI-lezers van de Rijksmap werken. Ze zijn gepubliceerd zoals ze zijn gebruikt, zodat iedereen kan nagaan hoe een label, samenvatting of plaatsing tot stand komt, en zodat een onafhankelijke lezer dezelfde ronde kan overdoen. Hoe de protocollen in de pijplijn passen, staat in [pijplijn-en-kwaliteit.md](../pijplijn-en-kwaliteit.md).

De protocollen verwijzen naar werkmappen en bestandsnamen uit de lokale pijplijn. Die scripts komen later in de repository (zie de [routekaart](../routekaart.md)).
