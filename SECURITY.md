# Beveiliging

Meld beveiligingsproblemen vertrouwelijk via **info@rijksmap.nl**, niet in een openbaar issue. Zie ook [`/.well-known/security.txt`](https://www.rijksmap.nl/.well-known/security.txt).

De Rijksmap is een statische site, zonder accounts, formulieren of code op een server. Wat een pagina mag laden, is beperkt door een Content Security Policy in de pagina zelf.
